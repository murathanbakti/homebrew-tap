# murathanbakti/homebrew-tap

Homebrew casks for [Nubrix](https://github.com/murathanbakti/nubrix), a notch bar for macOS built for developers.

```sh
brew tap murathanbakti/tap
brew trust --tap murathanbakti/tap
brew install --cask nubrix
```

Homebrew 7 only loads casks from non-official taps you have trusted, which is what `brew trust` does.

Nubrix is ad-hoc signed and not notarized, so macOS blocks the first launch. Open System Settings, Privacy & Security, and click "Open Anyway" next to the Nubrix message. You do not need to turn Gatekeeper off. See the [Nubrix README](https://github.com/murathanbakti/nubrix#first-launch-and-gatekeeper) for details and the optional Claude Code hook setup.

The cask is generated by the Nubrix release workflow (`scripts/render-cask.sh`).
